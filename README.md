# AI 提示词优化（AI Prompt Optimizer）

输入框旁的「✨ 优化」按钮：把当前草稿交给模型改写为更清晰、更完整的提示词，结果流式显示，可复制或一键替换回输入框。改写始终使用**发起会话时选中的模型**，不额外引入新的模型配置。

## 使用

1. 在输入框里写下想发送的提示词（草稿至少 1 个字符）。
2. 点击工具行左侧的「✨ 优化」。
3. 面板出现在输入框上方，边生成边显示优化结果；可切换方向后重新生成：
   - 通用：澄清意图、补全输出要求，贴近原长度
   - 结构化：拆成小标题 / 要点
   - 精简：去掉冗余，保留全部约束
   - 补充细节：补齐背景、约束与验收标准
   - 技术任务：按工程任务书写（技术栈、涉及文件、验收条件）
4. 「替换输入框」把结果写回草稿（可撤销），或「复制」后自行使用。

## 设计

- **只改写，不回答**：服务端系统提示词要求模型只输出优化后的提示词本身，不带前言、引号或代码围栏，并保持草稿语言。
- **事实不被编造**：缺失的具体信息用 `[框架]` 这类占位符表示，而不是让模型猜。
- **会话内一致的模型**：优先取该会话最近一次请求的 provider/model，回退到 Agent 配置，最后回退到 profile 默认选择。
- **流式**：`POST /prompt-optimizer/optimize` 以 NDJSON 逐行返回 `delta` / `done` / `error`，页面按行消费；中途关闭面板会中止上游请求。
- **不污染会话记录**：改写走独立 HTTP 端点，不写入会话日志，不产生命令行或消息。
- **鉴权**：路由先经过 `connection.requestRejection`（Host/Origin 防 DNS rebinding 与跨站请求，以及登录 cookie 校验），再读取有上限的 JSON body。
- **边界**：草稿上限 8000 字、body 上限 64 KiB、单次改写 120 秒超时、输出 1800 tokens。

## 组成

| 文件 | 作用 |
| --- | --- |
| `index.js` | Host 半：鉴权、参数校验、模型解析、流式改写端点 |
| `client.js` | 浏览器半：工具行按钮 + 输入框上方面板，共享每会话状态 |
| `cordis.patch.yml` | 插入 Host 插件行 `prompt-optimizer` |
| `locale/en.json`、`locale/zh.json` | 插件市场与插件列表中的标题 / 描述 |
| `icon.svg` | 插件图标（原创） |

无需任何依赖或构建步骤：Host 半只用注入的 Cordis 服务（`llm`、`agentDefaultModel`、`webServer`、`connection`），浏览器半只用模块表提供的 `react`。

## 卸载

在插件管理器中移除该 bundle 即可，不会残留配置或会话数据。
